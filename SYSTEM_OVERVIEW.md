# Complete System Overview

## TL;DR - The Three Commands You Need

```bash
# 1. Launch experiment (everything automatic)
./scripts/launch_smart.sh my_experiment bfvp parity arithmetic

# 2. Check status (optional)
experiments/my_experiment/status.sh

# 3. Analyze results
experiments/my_experiment/analyze.sh
```

**That's it!** Everything else is automated.

---

## What This System Does

### 🚀 Automated Experiment Pipeline

**One command launches everything:**

```
./scripts/launch_smart.sh my_experiment bfvp
                 ↓
         STAGE 1: Data Prep (Parallel)
         ├─ trace format       │
         ├─ final_value format │ } ~5-30 min
         └─ empty_trace format │
                 ↓
         STAGE 2: Training (Auto-start)
         ├─ cot (waits for trace)
         ├─ mdm (waits for trace)
         ├─ padding (waits for trace)
         ├─ padded_looping (waits for trace)
         ├─ classifier (waits for final_value)    } ~2-4 hours
         ├─ looping (waits for final_value)
         ├─ empty_padding (waits for empty_trace)
         └─ empty_padded_looping (waits for empty_trace)
                 ↓
         STAGE 3: Analysis (Manual trigger)
         ├─ Per-language comparisons
         ├─ Cross-language heatmaps    } Automatic grouping
         └─ Publication-ready outputs
```

### 📊 Intelligent Analysis

**Automatically:**
- Groups runs by language/task
- Compares algorithms within each task
- Creates cross-language comparisons ("which algo for which task?")
- Generates publication-ready plots and LaTeX tables
- Compares all 5 decoding strategies for MDLM

### ✅ What's Automated

1. **Data Preparation** - Caches all formats before training
2. **Job Dependencies** - Training auto-starts when data is ready
3. **Organization** - Results organized by experiment → language → algorithm
4. **Monitoring** - Auto-generated status scripts
5. **Analysis** - Auto-generated analysis scripts
6. **Metrics** - All metrics saved automatically (validation + test)

## Key Files

### Launch Scripts

**[scripts/launch_smart.sh](scripts/launch_smart.sh)** ⭐
- Main experiment launcher
- Handles data prep + training + dependencies
- One command does everything

**[scripts/prepare_data.sh](scripts/prepare_data.sh)**
- Prepares single data format
- Runs 1 training step to cache data
- Called by launch_smart.sh

**[scripts/run_single.sh](scripts/run_single.sh)**
- Runs single training job
- Generic wrapper for all algorithms
- Called by launch_smart.sh

### Analysis Scripts

**[compare_models.py](compare_models.py)** ⭐
- Main analysis script
- Automatic multi-language grouping
- Cross-language comparisons
- Decoding strategy analysis

**[analyze_metrics.py](analyze_metrics.py)**
- Single run analysis
- Training curves and test results

### Training Code

**[trainer_base.py](trainer_base.py)**
- Updated to save ALL metrics
- Includes all decoding strategies
- Saves validation_metrics.json and test_metrics.json

**[main.py](main.py)**
- Entry point with 3 modes: train, ppl_eval, sample_eval

**[algo.py](algo.py)**
- Algorithm implementations (AR, LT, MDLM)

## Algorithm Variants (8 per language)

1. **cot** - Chain-of-thought (AR with trace format)
2. **mdm** - Masked diffusion language model (MDLM)
3. **padding** - Padding baseline (trace format)
4. **padded_looping** - Padded looping transformer
5. **classifier** - Single-pass classifier (constant depth LT)
6. **looping** - Looping transformer (log depth)
7. **empty_padding** - Empty padding baseline
8. **empty_padded_looping** - Empty padded looping

- `cross_language_summary.csv` - All (language, algorithm) pairs

All runs together (useful for overall trends):
- Same structure as per-language directories

## Common Workflows

### Full Experiment

```bash
# Launch everything
./scripts/launch_smart.sh full_study bfvp parity arithmetic

# Monitor (optional)
experiments/full_study/status.sh

# When done, analyze
experiments/full_study/analyze.sh

# View key results
open experiments/full_study/analysis/cross_language_acc_exact.png
cat experiments/full_study/analysis/cross_language_summary.csv
```

### Single Language Test

```bash
# Quick test on one language
./scripts/launch_smart.sh quick_test bfvp

# Results in experiments/quick_test/
```

### Manual Single Job

```bash
# Run specific algorithm manually
sbatch \
  --export=ALL,TASK=bfvp,ALGO=cot,MODEL_LENGTH=256,OUTPUT_DIR=results/test \
  scripts/run_single.sh
```
