# Quick Start Guide

## Three-Step Workflow

### 1️⃣ Launch Experiment

```bash
./scripts/launch_smart.sh EXPERIMENT_NAME LANGUAGE1 [LANGUAGE2 ...]
```

**Example:**
```bash
./scripts/launch_smart.sh my_experiment bfvp parity arithmetic
```

**What it does:**
1. ⚡ Prepares all data formats in parallel (~5-30 min)
2. 🎯 Auto-launches all training jobs when data is ready (with dependencies)
3. 📊 Includes all 8 algorithm variants per language

---

### 2️⃣ Monitor (Optional)

```bash
experiments/EXPERIMENT_NAME/status.sh
```

**Or:**
```bash
squeue -u $USER
tail -f watch_folder/EXPERIMENT_NAME-*
```

---

### 3️⃣ Analyze Results

```bash
experiments/EXPERIMENT_NAME/analyze.sh
```

**Results:**
```
experiments/EXPERIMENT_NAME/analysis/
├── by_language/{task}/           # Per-task comparisons
├── cross_language_*.png           # Which algo for which task?
└── cross_language_summary.csv     # Full summary table
```

---

## Complete Example

```bash
# Launch (smart pipeline with all algorithms)
./scripts/launch_smart.sh test_run bfvp parity

# Wait for jobs to complete (auto-managed pipeline)...
# Data prep runs first, then training starts automatically

# Check status anytime
experiments/test_run/status.sh

# Analyze when complete
experiments/test_run/analyze.sh

# View results
open experiments/test_run/analysis/cross_language_acc_exact.png
cat experiments/test_run/analysis/cross_language_summary.csv
```

---

## Algorithm Variants (8 per language)

Per language, trains:
1. **cot** - Chain-of-thought (AR with trace)
2. **mdm** - Masked diffusion (MDLM)
3. **padding** - Padding baseline (trace format)
4. **padded_looping** - Padded looping transformer
5. **classifier** - Single-pass classifier (constant depth)
6. **looping** - Looping transformer (log depth)
7. **empty_padding** - Empty padding baseline
8. **empty_padded_looping** - Empty padded looping

---

## Available Tasks

- `bfvp` - Boolean formulas
- `arithmetic` - Arithmetic expressions
- `parity` - Parity checking
- `contains_a`, `ab_star`, `mod_3` - FSA tasks

## Smart Pipeline Workflow

```
./scripts/launch_smart.sh my_exp bfvp
                 ↓
┌─────────────────────────────────────┐
│ STAGE 1: Data Preparation (Parallel)│
├─────────────────────────────────────┤
│ ⏩ bfvp - trace format              │
│ ⏩ bfvp - final_value format        │
│ ⏩ bfvp - empty_trace format        │
│                                     │
│ ~5-30 minutes                       │
└─────────────────────────────────────┘
                 ↓
┌─────────────────────────────────────┐
│ STAGE 2: Training (Auto-starts)     │
├─────────────────────────────────────┤
│ 🚀 All 8 training jobs start        │
│    when their data is ready         │
│                                     │
│ ~2-4 hours (depending on config)    │
└─────────────────────────────────────┘
                 ↓
┌─────────────────────────────────────┐
│ STAGE 3: Analysis (Manual)          │
├─────────────────────────────────────┤
│ $ experiments/my_exp/analyze.sh     │
│                                     │
│ Generates all plots and tables      │
└─────────────────────────────────────┘
```

**Key benefit:** Fully automatic pipeline with proper job dependencies!

## Common Commands

```bash
# Check job status
squeue -u $USER

# Check pipeline progress
experiments/EXPERIMENT_NAME/status.sh

# Cancel all jobs
scancel -u $USER

# Cancel specific experiment
scancel -u $USER --name="EXPERIMENT_NAME-*"

# View data prep logs
tail -f watch_folder/dataprep-*

# View training logs
tail -f watch_folder/EXPERIMENT_NAME-*

# Rerun analysis
experiments/EXPERIMENT_NAME/analyze.sh
```

## Advanced: Manual Single Jobs

If you need to run a single algorithm manually:

```bash
# Submit single training job
sbatch \
  --export=ALL,TASK=bfvp,ALGO=cot,MODEL_LENGTH=256,OUTPUT_DIR=path \
  scripts/run_single.sh

# Prepare data only
sbatch \
  --export=ALL,LANGUAGE=bfvp,FORMAT=trace,MODEL_LENGTH=256 \
  scripts/prepare_data.sh
```
